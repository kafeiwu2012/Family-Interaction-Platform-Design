# OPPO R7sm 行车记录仪

独立原生 Android 应用，包名 `com.family.recorder`，与仓库原有家庭采集应用互不覆盖。面向 Android 5.0–8.x，最低 API 21；使用旧 Camera API 以兼容 R7sm。尚未在 OPPO R7sm 真机验收，不宣称已验证所有 ColorOS 固件。

## 功能

- 横屏深色仪表界面、实时时钟、录像状态、片段计时、低帧率实时预览（约 2 fps，以降低旧机功耗）。视频编码最高 30 fps，具体受设备配置限制。
- 内置 Movies/VehicleRecorder、应用专用存储、检测到的外置卡专用目录，以及最近 8 个预存路径；支持目录浏览和输入绝对路径。保存时实际创建测试文件验证可写。
- 自定义容量（MB），1/3/5 分钟分段，720p / 1080p，不支持所选画质时降级。默认 720p、3 分钟、2048 MB。
- 按时间删除最旧未锁定片段。当前片段预留空间和锁定片段均计入配额；保留额外 64 MB 物理空闲空间。容量小于一个预计片段时拒绝开始，不盲目删除。
- 前后摄像头切换（先保存当前片段），录音开关、硬件支持时电子防抖、后置常亮补光、0/90/180/270° 录像方向。
- 手动紧急锁定当前片段，录像库播放、锁定、解锁及删除。锁定录像不会循环删除，占满配额则停止并提示。
- 前台常驻通知、通知停止按钮、CPU 唤醒锁、服务独立 EGL 离屏预览；返回桌面、退出界面或按电源键熄屏后仍保持录制。暗屏按钮只降低屏幕亮度，真正熄屏请按电源键。

## 构建及安装

需要 JDK 17、Gradle 8.9、Android SDK Platform 35 和对应构建工具。用 Android Studio 打开本目录，配置 Gradle 8.9 后同步；或：

```sh
cd vehicle-recorder
gradle :app:assembleDebug :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

仓库 `.github/workflows/vehicle-recorder.yml` 自动构建并上传 `vehicle-recorder-debug` APK artifact。到 GitHub Actions 对应成功运行页面下载压缩包后解压安装。Debug APK 用于测试，自行分发时请配置私有 release 签名，勿提交密钥。

本地快速检查（只需完整 JDK 和 Python 3，不需要 Android SDK）：

```sh
bash tests/check.sh
```

检查覆盖真实 Java 文件系统配额逻辑、旧片段清理、锁定保护、部分文件计入容量、物理空间不足拒绝、非本程序文件保护，以及 Java 语法和 XML。语法检查不能替代 Android 编译、lint 或真机测试。

## R7sm 首次使用

1. 允许相机、存储权限；开启录音时允许麦克风。授权后再点击开始录像。
2. 停止状态进入设置，选择路径、配额和每段时长。外置卡请优先选应用专用目录：Android 5 的普通第三方应用通常不能写外置卡任意目录。应用专用目录会在卸载时删除，重要录像须先导出。
3. 在 ColorOS 的权限/电池管理中允许后台运行和自启动，并将应用锁定在最近任务中；各固件菜单名称可能不同。关闭针对本程序的省电清理。
4. 横屏固定手机，校准录像旋转角度，录制并回放确认画面方向。前置默认不额外镜像；界面时间不是写入视频像素的水印。
5. 点击开始，确认红色 REC 和计时递增，按电源键熄屏；数分钟后唤醒检查文件并播放。

## 录制与存储边界

- 这是分段循环录像。旧 Camera / MediaRecorder 每段需重新启动，分段和镜头切换存在短暂间隔，不能保证无缝录像。不是双摄同时录制。
- 只清理目标目录下符合 `VR_<毫秒时间>_[FB].mp4` 或 `.part` 命名的本程序文件，不会主动删除其他名称的文件。建议使用独立目录，不要将其他重要文件改成该命名。
- `.lock` 为片段保护标记，不计入视频配额的少量文件系统开销。配额限定本程序视频文件总大小，不是磁盘分区或预先占用磁盘；其他应用占用存储也会导致停止。
- `.part` 为录制中的 MP4；正常结束后改为 `.mp4`。系统强杀、断电、存储卡拔出可能留下无法播放的 `.part`，未锁定文件参与后续清理；锁定残片需手动检查和导出。未实现断电修复。
- 整个进程被系统强杀、用户强制停止或重启后不会自行开始。服务不使用自动重启，避免丢失状态后静默采集。
- 本版本没有开机自动录制、碰撞自动锁定、GPS/速度叠加、硬编码时间水印或停车监控。没有网络权限，不上传录像。
- 后台摄像头方案针对 Android 5–8 设计。Android 9 及更新系统、不同 ColorOS 固件可能限制后台相机；本版本不作为现代 Android 通用实现。`targetSdk 28` 是旧机专用兼容选择。
- 长时间录像、充电及补光可能增加发热；R7sm 长时间稳定性和熄屏能力须按下面的验收表实测。
