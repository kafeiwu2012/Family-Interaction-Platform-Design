## 本次改进

- **GPU 直接预览**：移除旧版每 500 ms 一帧、GPU 像素读回和 Bitmap 复制的显示路径。默认目标 30 fps，提供 15 fps 节能预览；录像帧率可选 24/30，设备能力不足时按配置降级。
- **录制中设置**：可随时打开三页设置面板。取消不打断录像；保存编码或存储设置会先保存当前片段，再按新设置继续，存在短暂切换间隔。仅预览帧率或自动启动变化无需切段。
- **打开软件自动录像**：默认开启，首次授权成功后直接开始；手动停止后从菜单、录像库返回不会自行重启。可在“运行偏好”关闭。
- **中文可读文件名**：`后摄像头_20261027_131205_123.mp4` / `前摄像头_20261027_131505_456.mp4`。使用手机本地时间，毫秒加碰撞序号防止覆盖；旧格式录像继续受管理。
- **全屏与折叠菜单**：预览占满整个应用窗口，默认收起面板；保留小型 REC 及醒目菜单标记，点击展开镜头、保护、录像库和设置操作。
- **手动横竖屏**：初始横屏，可切为竖屏并记住选择；方向变化自动保存当前片段后继续，存在短暂间隔。默认预览铺满时可能裁切边缘，可切换完整画面；保存视频不受预览裁切影响。

继续支持预存/自定义路径、256 MB 起的容量配额、1/3/5 分钟循环片段、前后镜头、720p/1080p、录音、电子防抖、后置补光、0/90/180/270° 安装校正、片段保护、回放及熄屏持续录像。

## 下载及安装

测试包放在 [downloads](downloads/)，GitHub Actions 成功构建也会上传 `vehicle-recorder-debug` artifact。正式分发请使用自行保存的 release 签名。

**从本仓库 1.0.0 测试包升级**：已核对，新旧测试包签名不同，不能直接覆盖安装。请先导出重要录像、记录原目标路径，再卸载旧版并安装新版；应用专用目录会在卸载时删除。新版不自动批量重命名旧视频；重新选择原共享存储路径即可管理旧文件。

首次打开允许相机及存储权限；录音启用时允许麦克风。进入“设置 → 循环存储”选目标目录，保存时实际验证可写；外置卡优先选择应用专用目录，Android 5 通常不允许第三方应用写外置卡任意路径。保留最近 8 个路径。

在 ColorOS 权限/电池管理中允许后台运行和自启动，并锁定最近任务。按电源键真正熄屏；暗屏按钮仅降低亮度。长时间录像前先校准方向、回放确认声音和画面，再按开发文档验收熄屏录像。

## 构建

JDK 17、Gradle 8.9、Android SDK Platform 35、AGP 8.6.1。Android Studio 可打开本目录并配置 Gradle 8.9。

```sh
cd vehicle-recorder
bash tests/check.sh
gradle --no-daemon :app:assembleDebug :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

包名 `com.family.recorder`，minSdk 21、targetSdk 28；后者是旧机相机和存储兼容选择，本项目不作为 Android 9 及更新系统的通用后台相机方案。

## 存储与录制边界

- 配额包含旧版和新版的本程序录像、当前片段及受保护片段；保护文件不自动删除，空间不足时停止提示。只清理本程序命名的文件，建议使用专用文件夹。
- 默认 2048 MB、720p、3 分钟。不是预分配磁盘分区，其他应用消耗空间也会导致停止；每段预留空间，录制中检查磁盘余量。
- `.part` 为录制中片段，正常结束改为 `.mp4`；断电、强杀或拔卡可能留下不可播放的残片，没有实现 MP4 修复。保护标记 `.lock` 须和原视频一起保存。
- 分段、镜头切换、编码或存储设置变化存在短暂间隔，不承诺无缝录像。仅一个摄像头录制，不是双摄同时录制。
- 系统强杀、重启或强制停止后不会由系统静默自动开始；自动录像仅指用户打开软件。
- 暂未实现碰撞自动锁定、GPS/速度叠加、像素时间水印或停车监控。界面时间不是写入视频像素的水印。无网络权限，不上传录像。
