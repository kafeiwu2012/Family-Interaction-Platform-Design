# 菜单图标与轻量点击反馈 · 1.2.2

## 外观

右上角使用 52dp 圆形点击区域，青绿色描边、深色背景。关闭状态显示居中的矢量齿轮，展开后显示居中关闭图标；移除“菜单/收起”文字，避免字体基线和系统按钮内边距导致视觉偏下。ImageButton 使用 CENTER_INSIDE 与四边相同的 13dp 内边距。中文 contentDescription 仍分别为“展开操作菜单”和“收起操作菜单”，供无障碍读屏使用。

菜单仍可点击展开/收起、返回收起以及 8 秒无触摸自动收起。

## 动效与开销控制

仅用户点击右上角图标时播放一次：

- 第一阶段：约 90ms，放大到 1.08 倍、向上移动 3dp。
- 第二阶段：约 150ms，恢复 1 倍和原始位置。

时间为系统动画比例为 1 时的目标值。使用 Android ViewPropertyAnimator 的 scaleX/scaleY/translationY，只变换该按钮，不修改布局尺寸、不重排布局，不对相机 TextureView 或整个控制面板添加动画。

没有循环动画、常驻动画定时器、模糊、位图截图、动画库或新增后台线程。原有录像、GPU 预览和编码参数未修改。稳定状态及熄屏后不保留动画回调。

动画本身需要短暂 UI/GPU 渲染，不能承诺严格“零瞬时功耗”。本实现将开销限制在点击后的短时间内，没有测得 R7sm 的具体功耗或帧率差值，不宣称已完成性能实测。

## 取消与降级

- 连续点击：先取消旧动画并清除结束回调，复位后再响应本次点击，不叠加播放。
- 自动收起、方向切换、暂停/熄屏、退出界面：取消动画并恢复原位。
- PowerManager.isPowerSaveMode 为 true：直接切换菜单，不播放动画。
- 系统 ANIMATOR_DURATION_SCALE 为 0：直接切换菜单，不播放动画。只读取系统设置，不修改系统设置。

使用现有 Android API（minSdk 21），没有新权限和第三方运行时依赖。

## 资源与实现

- `res/drawable/ic_menu_gear.xml`：24dp 矢量齿轮。
- `res/drawable/ic_menu_close.xml`：24dp 矢量关闭图标。
- `MainActivity.setExpanded`：图标和菜单状态切换。
- `MainActivity.animateMenuTap/resetMenuMotion`：一次性点击反馈与生命周期复位。

## R7sm 验收（待真机）

1. 横/竖屏中齿轮及关闭图标居中，点击区域不被裁切。
2. 点击时有轻微上浮回弹，松开后回到原位；快速连续点击不漂移，展开状态与图标一致。
3. 录制中频繁开关菜单，观察预览和保存文件；确认无新增明显卡顿。实际功耗需同环境对比。
4. 动画中旋转界面、返回或熄屏后再进入，按钮位置和缩放正常。
5. 开启系统省电模式或关闭动画后，菜单正常操作，动效不播放。
6. 8 秒无触摸自动收起、读屏描述及前置竖屏预览修复继续正常。
