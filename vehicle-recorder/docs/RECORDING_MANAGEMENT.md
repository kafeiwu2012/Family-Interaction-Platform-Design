# 录像管理：多选、批量删除、导出与分享 · 1.3.1

## 入口

主界面右上角齿轮 → 录像库。此前行车记录仪版本只提供单条播放、保护和删除，没有批量及导出入口；1.3.0 补齐这些操作。

- 点“多选”或长按录像进入选择状态；点录像行勾选/取消，标题显示已选数量。
- “全选当前”仅选择当前筛选下已显示的录像；“取消选择”清除勾选和计数，但不删除录像。
- 切换全部/已保护/前/后筛选时清空选择，避免误操作隐藏的录像。
- 点击“完成”或返回键退出多选。窄屏下操作栏分为两行，所有按钮直接可见；横屏宽度足够时为一行。“删除所选”为独立红色按钮，紧邻“全选当前”，删除前仍需确认。
- 点击单条录像仍可播放、保护/解除保护、导出、分享、删除或进入多选。
- “目录”可浏览当前保存位置、默认目录及最近预存路径，不改变正在录制的保存位置。

## 批量删除

删除前显示数量并要求确认。只处理所选源目录下、符合本程序新旧命名规则的已完成 `.mp4`。保护录像自动跳过；当前录制 `.part`、外部目录、无关命名不会删除。保护判断与删除在 LoopStore 类锁内完成，与循环清理和录像库保护操作协调。

结果分别报告删除、保护跳过、已不存在及失败数量。不会为了完成批量删除自动解除保护。删除不可撤销，请先导出重要录像。

## 导出副本

选定录像后点“导出”，有两种方式：

1. **系统目录 / SD 卡**：Android 系统选择器允许选择并授权目标目录，适配外置卡不能直接写路径的情况；不要求永久保存目录授权。
2. **本地路径**：默认 Movies/VehicleRecorderExports，可输入绝对路径。仅可写目录能成功；外置卡受限目录优先用系统选择器。

每次在目标父目录中新建 `录像导出_yyyyMMdd_HHmmss_SSS` 子目录，保存所选视频副本。局部重名会选择另一个子目录，不覆盖以前导出的文件。原视频名保留。复制保护录像不会解除其保护，导出不主动删除原录像；导出的副本不附带本程序 `.lock` 标记。

本地复制先写临时文件，完整复制并关闭流后改为目标名字；失败或取消时删除未完成临时文件。系统目录方式由 DocumentsContract 创建新文件，失败或取消尽力删除当前未完成文件。已完成的副本在取消后保留，并报告完成、失败与未处理数量。系统进程被强杀、拔卡、远程文档提供者阻塞或拒绝清理时，目标端可能残留未完成文件；不提供崩溃后断点恢复。

目录选择器不可用时可使用本地路径。目录选择器暂停/重建 Activity 时保留待导出源路径和选项，用户取消选择则不创建输出。

录像仍可能继续循环清理：在目标选择器等待期间，未保护的旧片段可能已经消失，结果按实际失败报告。开始复制每个文件时，在类锁内验证范围并打开输入描述符，随后释放类锁再进行 I/O；已经打开的文件被删除后，Linux 文件描述符仍支持复制，避免长时间占用相机的清理锁。重要录像建议先保护后导出。大量导出会增加磁盘 I/O 和可用空间压力，连续录像时需留足空间；导出子目录不会计入当前目录的非递归视频配额，但仍占用实际磁盘。

## 分享

单条或多选均可调用 Android 分享面板，最多 100 个/次；更多录像请分批或使用目录导出。仅向用户选定的接收应用临时授予只读 content URI；不自动发送、不授予写权限、应用本身不联网。

分享直接引用原录像，不创建额外副本。接收应用读取前原文件可能被循环覆盖，重要录像请先保护或导出。接收应用是否支持多视频由该应用决定；没有接收应用时使用目录导出。

ClipProvider 仍只允许当前、默认和预存目录中的本程序已完成录像，未扩大到任意文件路径。

## 实现与性能

- ClipsActivity：选择、筛选、确认、目录选择、进度与结果；列表复用行视图。
- ArchiveFiles：纯 Java 的源范围验证、保护跳过、打开源文件、流式复制与本地导出提交。
- 64 KB 复制缓冲；任务只在用户发起时运行，使用现有单线程 I/O 执行器，进度更新节流至约 150ms。
- 不用全局长锁跨越复制过程，不启动常驻导出服务、后台扫描或网络上传。
- 取消通过显式标记传给复制循环；避免任务尚未开始便取消 Future、导致 UI 永久忙碌的问题。界面销毁时中断并清理任务。

## 1.3.1 操作含义与刷新

1.3.0 的“清空”实际只执行取消选择，不是删除文件；操作条总宽度超过常见竖屏窗口宽度，删除入口可能位于屏幕右侧。1.3.1 将名称明确为“取消选择”和“删除所选”，窄屏两行展示，减少误解。

取消选择会清空选择集合、ListView 选择缓存、已选数量，重新绑定可见勾选状态；重新滚动进入的行仍从同一选择集合读取状态。空选择禁用删除/导出/分享按钮，不能继续对之前全选的文件操作。该路径仅更新 UI，不删除文件、不重新扫描磁盘、不新增后台任务。

真机复现检查：全选当前 → 取消选择 → 已选 0/全部未勾选/删除禁用；再次勾选一条 → 已选 1/导出及删除启用；切换筛选和目录后旧选择清空。实际删除需全选当前 → 删除所选 → 确认，保护录像仍自动跳过。

已根据用户补充确认：本次需求是删除所选录像。因此第一行优先排列“全选当前”和红色“删除所选”；“取消选择”单独保留，用于不删除文件的撤销勾选。
