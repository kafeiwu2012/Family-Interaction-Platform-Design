# 更新记录

## 1.2.0

- 手动切换横屏或竖屏，初始默认横屏，记住选择；预览与后续录像方向同步。
- 读取前后摄像头安装角度，方向改变后安全保存片段并继续，支持叠加安装校正。
- 强化全屏与沉浸式显示，预览默认铺满，可切换完整画面，保存视频不受预览裁切影响。
- 默认隐藏操作面板，保留醒目菜单按钮和小型 REC 状态；点击展开、再次点击/返回收起，8 秒无触摸自动收起。
- 横竖屏可滚动面板、录像库跟随方向；配置变化不重复触发启动录像。
- 新增方向/显示几何测试及 DISPLAY_MODES.md 开发和使用说明。

## 1.1.1

- 新增“相机 + 道路”品牌图标，提供五档桌面 PNG 与 Android 8 自适应图标。
- 应用标题栏使用新图标，录制通知使用独立单色小图标。
- 提供 SVG 源文件和可重复生成 PNG 的脚本；不改变录像功能及设置。

## 1.1.0

- 将约 2 fps 的 Bitmap 预览替换为 GPU 直接预览，移除像素读回和逐帧位图分配；支持目标 15/30 fps 预览、24/30 fps 录像。
- 打开应用默认自动录像，首次权限授权后继续自动开始；可在设置中关闭。
- 录制中可打开菜单、修改和保存设置；仅改变预览/启动偏好不切段，编码和存储变化自动保存旧片段再继续。
- 文件名改为前/后摄像头、本地日期、时间、毫秒，处理同名碰撞；兼容旧录像的管理和循环清理。
- 全屏视频叠层、REC/时间 HUD、侧边快捷按钮、三页设置、容量进度和筛选式录像卡片。
- 文件统计及目录验证移出 UI 线程；添加命名和设置策略测试。
- 新增开发说明、性能原因分析和 R7sm 回归清单。

## 1.0.0

基础循环录像、容量和路径设置、镜头切换、锁定、回放、前台服务及熄屏录制。
