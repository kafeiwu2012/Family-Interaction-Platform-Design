# OPPO R7sm / Android 5.1.1 真机测试

以下是待执行步骤，不是已通过结果。记录手机型号、ColorOS/固件版本、API、摄像头报告、APK SHA256、服务器版本以及每项结果。

1. `adb shell getprop ro.build.version.sdk` 应为 22；安装 APK。启动查看摄像头能力，记录 front/back ID 和 hardwareLevel。没有某颗摄像头时应显示拍摄失败，不应自动使用另一颗。
2. 配置 HTTPS/令牌，在手机浏览器验证域名、证书和系统时间；启用定时拍摄。确认常驻通知可见、可打开界面、可停止。检查服务器生成可解码 JPEG，前后摄图像朝向和清晰度（本版仅单次自动曝光，无预热预览，暗光效果需实测）。
3. 设置间隔 10 秒，亮屏 5 分钟，核对时间和文件数量。界面切后台后保持拍摄。熄屏 30 分钟、2 小时各测一次，核对服务器文件间隔、耗电、温度、是否出现黑图或 Camera2 错误；不得用亮屏测试替代熄屏结论。
4. ColorOS 电池设置允许后台运行、锁定任务后重复；分别测试默认省电和允许后台设置，写明必要配置。被系统限制时记录错误，不宣称通过。Camera2 LEGACY 实现如果无预览拍照失败，需要后续实机调整。
5. 管理端切 front→back→front，各拍 10 张，通过现场不同目标确认实际镜头。切换发生在下一张，不要求中断当前拍照。重复快速切换，确认不会并发打开摄像头或崩溃。
6. enabled=false 后等待当前拍摄完成，至少两倍间隔无新文件；true 恢复。手机点击通知“停止”后不再上传/拍照；远程配置不能重新激活，重启手机也不能自启。
7. 飞行模式 10 分钟后恢复，观察补传；用文件名核对无丢失/重复。联网中停止服务，重新本机启动后补传。模拟服务端丢失上传响应，确认同名重试只保留一份。
8. 错误设备令牌、管理员令牌、TLS 证书分别测试。错误令牌应 401，设备令牌不能修改管理配置。无信任证书时不应降级 HTTP。检查日志和 Git 无令牌。
9. 小容量测试机或专用测试分区模拟低磁盘，确认手机暂停新增、已有文件保留；树莓派低磁盘拒绝上传，手机保留待重试。不要为测试填满日常使用的系统分区。
10. 与系统相机竞争、拔网、杀进程、重启服务器、重启手机分别测试。服务不自动重启是设计行为；本机重新启动恢复队列。手机强停后状态超过90秒离线。
11. 连续运行24小时，记录最大队列、上传延迟、失败率、温度、电量。前后摄各至少熄屏运行2小时；所有相关项通过后才能称该固件已适配。

双摄并发：API 22 不提供 `getConcurrentCameraIds`（API 30）。本版报告未知，所有测试只交替打开；hardwareLevel 不能作为并发支持证据。需要专门的后续诊断版本和现场测试才能确认并发。

后续第二版：先在 R7sm 验证 MediaRecorder + 单摄分段、片段崩溃恢复和音频权限，再评估实时视频编码/传输与树莓派3B负载。不能将本版 JPEG 上传视为录像或实时视频已实现。

## v0.2.0 无服务器本地测试

1. 直接覆盖安装 v0.2.0 APK，勾选“本地测试：无需服务器，不上传照片”。地址和令牌留空；不需要 Wi-Fi、热点或移动网络。
2. 间隔设为10秒，选择后置，点击“同意并启动”。确认常驻通知出现，界面状态显示“已保存本地”；等30秒后点击停止，再进“查看本地测试照片”，确认有可解码的现场照片。
3. 返回启动，运行中选择前置，等待下一张；停止后打开列表，通过文件名 front/back 和照片内容确认镜头。切换不会打断正在进行的一张拍摄。
4. 熄屏5分钟，解锁后停止，查看文件名时间是否持续增长、图片是否正常；再分别做前后摄2小时测试。失败时拍下界面/通知状态。LEGACY 摄像头无预览拍照的兼容性仍以真机为准。
5. 长按列表中的照片可确认删除；本地照片上限约256MiB，低可用空间或达到上限会暂停拍照，不自动删除旧照片。
6. 改模式或间隔需先停止、再启动；本地镜头选择可在运行中切换。取消本地测试才使用原有HTTPS上传模式。本地测试照片独立存储，不会因切回上传模式自动上传。卸载或清数据会删除这些照片。
7. 界面状态为最近事件和时间，不代表进程一定存活；强停/系统杀进程后可能显示旧事件，结合常驻通知、文件时间判断。
