# LanBridge 局域网文件共享

**[下载 Windows 软件包（含 x64 / ARM64 EXE 和源码）](downloads/LanBridge-Windows.zip?raw=true)** · [SHA-256 校验值](downloads/SHA256SUMS.txt)

Windows 独立 EXE + 浏览器界面。适用于 Windows 10/11，iPhone/iPad 使用 Safari，无需安装 iOS App。默认只共享独立目录，不扫描系统盘。

## 使用方法

1. 解压，双击与你的电脑架构匹配的 EXE。普通 Intel/AMD 电脑选择 `LanBridge-Windows-x64.exe`，Windows ARM 电脑选择 ARM64 版。无需安装 Go 或其他运行时。
2. Windows 自动打开操作页面。程序控制台需要保持打开。如果 Windows 防火墙询问，只为可信的专用网络允许访问。
3. 电脑和 iPhone/iPad 连接同一 Wi-Fi。在 Safari 输入程序窗口显示的“手机/iPad”完整网址（包含 `#` 后面的口令）。没有使用完整网址时，输入 `#` 后的连接口令。
4. 双向上传和下载：电脑和手机均可在页面上传；共享空间中的文件可由任意已连接设备下载。手机上传时使用系统文件选择器；下载后可通过 Safari 的下载列表保存到“文件”。
5. 点击文件名预览；通过右侧菜单复制、删除、移动、改名。新建目录后进入目录上传。复制支持单个文件，移动支持文件或文件夹。
6. 关闭程序控制台即停止共享。每次启动生成新口令。

默认目录：`%USERPROFILE%\LanBridge共享`。可以直接用 Windows 资源管理器放入或取出文件。

自定义目录和端口：

```powershell
.\LanBridge-Windows-x64.exe -root "D:\手机共享" -port 8765
```

建议使用本地 NTFS 磁盘上的专用共享目录。程序不会自动更改防火墙、注册表、磁盘分区或苹果设备文件系统。该版本保留控制台以显示连接地址并控制服务生命周期。

## 功能与可靠性措施

- 支持图片、音视频、PDF 预览（具体编码取决于设备浏览器）；UTF-8 文本预览和编辑最大 2MB。Word/Excel 等文件需下载到对应应用打开。
- 上传分块为 2MB，各块 SHA-256 核验，写入后同步至磁盘，网络失败自动重试最多 4 次；同一页面、同一服务进程内已确认的块无需重复传输。上传有进度条、字节数和取消按钮。
- 临时上传文件存放在 `.bridge/incoming`。全部上传完成后通过同卷硬链接安全创建最终文件，不覆盖现有目标；最终返回文件 SHA-256，便于外部复核。不支持硬链接的磁盘会报错而非降低提交安全性。
- 小于等于 128MB 的下载在页面显示进度；更大文件使用两分钟有效的签名链接交给浏览器流式下载，进度在浏览器下载列表查看。下载在 HTTP/TCP 传输错误时需重试，未实现跨重启的断点续传。
- 删除为移入 `.bridge/trash`，文本编辑前也在该目录备份原文件。编辑使用内容摘要检查冲突，临时文件同步后替换。恢复时请关闭程序，通过资源管理器把备份复制回所需位置；备份名有随机前缀。
- 路径限制在共享目录，拒绝路径穿越、隐藏目录、符号链接及 Windows 保留名称；所有操作要求连接口令。

## 范围与限制

- iOS 沙盒限制：只能管理电脑共享空间，以及用户主动从 iOS 文件选择器上传/下载的文件。网页不能直接删除或修改 iPhone/iPad 其他 App 的文件、系统目录或原始照片库；上传和下载不会自动删除手机原件。
- 这是可信局域网版本，使用 HTTP，连接口令和文件内容没有 TLS 加密；不适合公共 Wi-Fi，不要把端口映射到公网。完整网址和口令相当于共享空间的访问权限。未实现用户分级和只读权限。
- 保持 Safari 在前台，iOS 锁屏或后台可能暂停网络。关闭页面、停止服务后不能恢复原上传会话；重新选择上传即可。遗留临时文件可在停止服务后从 `.bridge/incoming` 清理，备份也需要按需手动清理。
- 共享目录内的文件应由可信用户管理。程序运行时不要用其他工具修改内部目录、建立链接/重解析点或同时改动正在编辑的文件。路径检查不是对本机恶意进程的隔离机制。
- 分块校验、同步写入和备份能降低中断风险，但无法对磁盘故障、断电或操作系统崩溃作绝对无损保证；重要文件仍应另行备份。
- 已在 Linux 环境通过自动化接口测试及交叉编译；尚未在 Windows 和 iPhone/iPad 真机上运行验证。EXE 未做代码签名，Windows 可能显示未知发布者提示；企业环境请遵循自身软件安装规定。

## 从源码构建

Go 1.25 或更新版本，无第三方依赖。

```powershell
go test ./...
$env:GOOS="windows"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go build -trimpath -ldflags="-s -w" -o LanBridge-Windows-x64.exe .
```

自动化测试覆盖：分块哈希错误、重复提交、未完成文件不可见、同名保护、路径穿越和符号链接拦截、鉴权、跨来源请求拒绝、文本编辑冲突、旧版本备份、复制、移动、软删除、签名下载和签名篡改。
