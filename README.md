# Family Capture · v0.3.0 源码

Android 5.1.1 / API 22 定时拍照 → HTTPS → 树莓派 3B（或 Linux 云主机）。仅用于知情且授权的拍摄。摄像头运行有常驻通知和本机停止按钮，不开机自启、不远程唤醒已停止的服务。

已实现源码：定时拍照、前后摄交替选择、熄屏期间 partial wake lock、JPEG 私有文件队列、断网重试、幂等上传、设备/管理员分离令牌、远程暂停/恢复/切摄/调间隔、在线状态和摄像头能力报告。Android 端没有第三方运行时依赖，所有调用以 API 22 为基线。

**尚未实现：上传录像、正常任务中的双路录像控制、实时视频、云存储适配器、推送告警、自动清理服务器历史文件、多设备管理。** 本地短录像循环与并发媒体诊断见 v0.3.0。 云主机可部署同一接收服务。API 22 无标准双摄并发枚举接口；普通拍摄保持串行，可通过 v0.3.0 的显式诊断尝试并发媒体操作。

**验证状态：已编译 debug APK，执行 Android Lint 和服务端集成测试；APK 使用兼容 API 22 的 v1 签名。未在 OPPO R7sm 实测，不能据此宣称熄屏拍摄已适配成功。** ColorOS 可能限制后台相机、唤醒锁或杀死进程；硬件以真机结果为准。第一版面向 API 22，不承诺现代 Android 后台摄像头行为或应用商店上架兼容性。

## v0.2.0 本地测试

[下载本地测试版 APK](downloads/family-capture-0.2.0-debug.apk)。勾选“本地测试”，无需填写服务地址/令牌，即可定时拍照、切换前后摄，并在应用内查看和删除测试照片。无需连接 iPhone 热点。照片存于应用私有目录，与补传队列分开，不自动上传；约256MiB上限。更改模式/间隔须先停止再启动。真机熄屏行为尚待测试。

## v0.3.0 批量管理与短录像

[下载 v0.3.0 APK](downloads/family-capture-0.3.0-debug.apk)。本地媒体支持点击多选、全选、确认批量删除、导出 ZIP（系统选择保存位置，原文件保留）、长按预览照片或视频。新文件名例：`前摄_2026-10-27_14-30-00-123_+0800_a1b2c3d4.jpg`；含手机本地日期时间、毫秒、时区和唯一后缀。旧文件不重命名，列表和导出时转换为可读名称。

本地循环可设置拍照时段、拍照间隔、无声录像时长（2–60秒，默认5秒）及录像后等待；各阶段串行，录像期间不拍照。镜头切换在下次操作生效，模式/时长修改须停止后启动。上传模式仍只支持照片，需同步更新服务端以接收新中文文件名；不上传本地短视频。

新增显式双摄诊断：停止普通拍摄后，实际尝试两路 JPEG 会话同时就绪后拍照，再尝试两路5秒无声录像。结果区分并发拍照和并发录像，录像须产生有效片段且录制重叠至少1秒。成功仅代表本次配置，不能推断精确同步或录像中拍照支持。离开主界面/点击停止取消诊断，正常模式保持串行。OPPO R7sm 结果仍须现场执行并检查文件，不根据 LEGACY 等级推断。

## v0.3.1 界面和播放修复

[下载 v0.3.1 APK](downloads/family-capture-0.3.1-debug.apk)。列表改为可换行且自适应高度，点击预览/播放、右侧勾选批量操作。视频改用独立 SurfaceView/MediaPlayer 页面，通过文件描述符读取私有目录，提供进度、暂停和错误码；旧片段本身损坏时仍需导出核验。设置按保存位置、拍摄方式和启停分组，隐藏无关参数并实时解释阶段顺序及预计张数。运行时锁定方案参数，镜头仍可本地切换。R7sm并发测试已反馈错误2，本次触发同时可用摄像头上限，正常模式继续串行。
